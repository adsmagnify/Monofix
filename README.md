# MONOFIX Packaging Solutions

Next.js (App Router) website for MONOFIX Solutions LLP — packaging, design, sustainability and EPR.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## What’s on the site

- Home carousel using the supplied visuals
- About, Why MONOFIX (three-column layout + CAE/FEA), six service verticals
- Gallery, Sustainability & EPR, Insights (price-feed placeholders), case studies
- Contact form (opens mail to `sales@monofix.co.in`)
- USA / EU priority pop-up after 4 seconds, right side, no page dimming
- Packaging made easy / pay-and-use placeholder

Copy is taken from the July 2026 content brief and the project email thread. Live polymer prices and the pay-and-use calculator are marked as pending until those feeds/apps are connected.
